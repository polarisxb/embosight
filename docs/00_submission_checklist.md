## 三、CRAIC 评分公式记忆点（每写一段都对照）

```
总分 = ((0.8 × A + 0.2 × B) / 100) × (0.3 × C + 0.25 × D + 0.4 × E + 0.05 × F)

A = 项目可行性与实用性 (权重 80% - 决定上限)  ← 报告每一段都要呼应
B = 项目技术难度 (权重 20%)
C = 项目创新度 (权重 30%)                    ← 零样本三创新点
D = 项目完成度 (权重 25%)                    ← demo + 实验数据
E = 队员对作品的贡献程度 (权重 40%)           ← 单人队天然满分
F = 答辩过程表现 (权重 5%)
```

**写作铁律**：每写完一段，自问"这一段在哪个评分项加分？"
