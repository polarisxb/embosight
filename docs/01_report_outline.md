## 写作铁律

1. **每写一段对照评分公式**：总分 = ((0.8A+0.2B)/100) × (0.3C+0.25D+0.4E+0.05F)
2. **A 项（实用性，权重 80%）是乘子**——可行性论证不到位，再创新都没用
3. **C 项（创新度）= 零样本三创新点**，必须明确"我新在哪"
4. **用数据说话**——具体数字、表格、对比，绝不写"大幅提升"
5. **图表至少 8 张**——架构图、流程图、对比图、消融图、demo 截图

### 第 3 章 项目背景和国内外研究现状（4-6 页）

#### 3.1 项目背景（1.5-2 页）

子节框架：

```
3.1.1 视障人士面临的现实困境
  - 数据：1731 万视障，独立生活困难占比 X%
  - 高频痛点：找物（每天 N 次）、避险、环境理解
  - 心理影响：孤立感、依赖感、安全焦虑
  ⭐ 这一节决定 A 项分数，必须有真实数据 + 真实场景

3.1.2 现有视障辅助方案
  - 导盲犬：成本 12-15 万元/只，覆盖率 <1%
  - 盲杖：被动避障，无法取物
  - 屏幕阅读器：解决数字鸿沟，物理世界无能为力
  - 智能音箱：能听指令，不能动手
  - 商业化机器人：如 OrCam MyEye（仅识别），价格高昂

3.1.3 AI 助盲技术发展现状
  - 视觉-语言模型在助盲中的初步应用
  - 具身智能的最新进展
  - 大模型 + 机器人融合趋势

3.1.4 政策导向
  - 《无障碍环境建设法》2023年实施
  - 国务院《数字无障碍行动方案 2025》
  - 《"十四五"残疾人保障和发展规划》
  ⭐ 这一节大幅加 A 项政策契合度
```

#### 3.2 国内外研究现状（2-3 页）

按主题分四个小节，每节 0.5-1 页，每节至少 4-6 篇引用文献：

```
3.2.1 视觉-语言-动作（VLA）模型研究
  - 关键论文：OpenVLA (2024)、π0 (2024)、Octo (2024)、SmolVLA (2025)
  - 现状：训练数据上表现好，零样本泛化能力有限
  - 不足：未针对视障辅助场景

3.2.2 主动感知（Active Perception）研究
  - 关键论文：Active Neural SLAM、Next-Best-View 系列
  - 现状：传统几何方法已成熟
  - 不足：未与大模型结合，未应用于助盲

3.2.3 视觉-语言模型（VLM）在无障碍中的应用
  - 关键论文：Be My Eyes + GPT-4V、SeeingAI
  - 现状：单图描述已可用
  - 不足：被动感知，无法主动获取多视角信息

3.2.4 零样本任务泛化
  - 关键论文：Zero-Shot RL、Foundation Policy
  - 现状：通用任务有进展
  - 不足：视障辅助专属零样本研究空白
```

#### 3.3 研究空白与本文工作（0.5 页）

```
现有研究的三大空白：
1. 视障辅助场景下的任务分解 → 通用任务分解不懂视障需求
2. 视障辅助场景下的主动感知 → 被动单图描述不够
3. 视障辅助专用的描述生成 → 通用 VLM 输出不友好

本文工作正是针对这三个空白，提出 EmboSight 系统。
```

#### 4.2 创新点①：零样本视障任务分解（1-2 页）

```
4.2.1 问题描述
  - 通用 LLM 任务分解忽视视障者关键维度（距离、触觉、安全）
  - 视障辅助数据集稀缺，必须零样本

4.2.2 方法设计
  - 视障专属任务模板库（10 类，覆盖 50+ 子任务）
  - Few-shot Prompt 设计
  - 任务分解树结构

4.2.3 算法流程（伪代码）
  function task_decompose(query):
      examples = retrieve_blind_examples(query, k=3)
      prompt = build_blind_aware_prompt(query, examples)
      subtasks = LLM(prompt)
      return validate_and_filter(subtasks)

4.2.4 关键创新
  - 视障专属维度强制编码（方位、距离、触觉、安全、行动）
  - 模板库可外部扩展，不依赖训练
```

#### 4.3 创新点②：零样本主动视角规划（2-3 页）⭐ 重点详写

```
4.3.1 问题描述
  - 单视角 VLM 信息不全
  - 经典 NBV 方法依赖几何先验，不适配语言驱动场景

4.3.2 离散视角库设计
  - 12 个标准视角（顶/左/右/前/后 × 远/近 × 倾斜）
  - 每个视角参数：位置 (x, y, z) + 朝向 (roll, pitch, yaw)

4.3.3 LLM-NBV 决策算法
  function active_planner(subtasks, observations):
      while not all_subtasks_covered(subtasks, observations):
          next_vp = LLM_choose_viewpoint(subtasks, observations, viewpoint_lib)
          new_obs = execute_viewpoint(next_vp)
          observations.append(new_obs)
      return observations

4.3.4 早停机制
  - 当 LLM 判断"信息已足"时主动终止
  - 平均扫描视角数 vs baseline

4.3.5 关键创新
  - 首次将 LLM 引入视障辅助 Active Perception
  - 离散视角库降低工程复杂度
  - 任务驱动而非几何驱动
```

#### 4.4 创新点③：零样本视障友好描述（1-2 页）

```
4.4.1 问题描述
  - 通用 VLM 输出对视障不友好（缺方位/距离/安全）

4.4.2 视障专属 Prompt 模板
  - 五维度强制输出
    ① 物体识别（名称 + 形状特征）
    ② 方位距离（前/后/左/右 + cm 级距离）
    ③ 触觉特征（材质 + 温度 + 形状）
    ④ 安全提示（热/冷/锋利/易碎）
    ⑤ 行动建议（怎么取/怎么避）

4.4.3 几何后处理
  - 利用仿真器深度图反推真实距离
  - 厘米级精度

4.4.4 视障友好词汇库
  - 触觉描述：圆筒形/长方体（避免颜色描述）
  - 温度提示：温热/常温/凉
  - 危险等级：高/中/低

4.4.5 关键创新
  - 第一个系统性将 Accessibility 设计学引入 VLM
  - 自定义评估指标：视障友好度（5 维度加权）
```

#### 4.5 仿真环境与评估方法（1-2 页）

```
4.5.1 仿真平台：RoboCasa
  - 100+ 厨房场景
  - Franka Panda 机械臂
  - MuJoCo 物理引擎

4.5.2 任务设计
  - Seen tasks（训练集）：5 个视障查询场景
  - Unseen tasks（测试集）：10 个全新场景（零样本评估）

4.5.3 评估指标

  - 视角规划成功率（覆盖任务子目标的概率）
  - 视障友好度评分（5 维度，主观+客观）
  - 物体距离精度（cm）
  - 端到端任务成功率

4.5.4 Baseline 对比
  - B1：固定视角扫描 + 通用 VLM
  - B2：随机视角 + 通用 VLM
  - B3：本文方法（消融 1：去掉 ①）
  - B4：本文方法（消融 2：去掉 ②）
  - B5：本文方法（完整版）
```
