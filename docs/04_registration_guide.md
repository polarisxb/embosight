# EmboSight - 报名表填写指南

> 用途：CRAIC 报名表（A、B、C、D、E 五部分）填写参考
> 格式参考：CRAIC PDF P19-25
> 提交方式：PDF + 部分纸质签字（视各赛区要求）

---

## 报名表整体结构（按 CRAIC PDF）

```
项目名称：EmboSight——零样本视障具身辅助智能体
项目成员：[你的名字]（单人队）
指导教师：[导师姓名]
所在学校：[学校全称]

A 部分：参赛队员情况（每个队员一栏）

D 部分：申报者确认事宜（签字）
E 部分：资格确认（指导教师盖章）
```

### 单人队的"项目分工"建议写法（这一栏决定 E 项 40% 权重）

```
作为单人队伍负责人，本人独立完成本项目全部工作，包括：

1. 项目立项与方案设计：调研视障辅助场景需求，
   确定研究目标与技术路线；

2. 系统架构设计：设计 EmboSight 整体架构，
   包括三大核心模块（任务分解、主动视角规划、视障描述）
   的接口与数据流；

3. 算法实现与代码开发：独立完成全部约 [1500-2000] 行代码，
   涵盖仿真接入、模型集成、Prompt 工程、评估脚本等；

4. 仿真环境配置：搭建 RoboCasa 仿真环境，
   配置 Franka 机械臂、摄像头与物理引擎；

5. 模型集成与调优：本地部署 Qwen2.5-VL，
   集成 DeepSeek API，设计视障专属 Prompt 模板；

6. 实验设计与执行：设计 Seen/Unseen 任务划分，
   完成消融实验、对比实验，整理实验数据；

7. 文档编写与材料制作：独立完成项目研究报告、
   查新报告、答辩 PPT、演示视频；

8. 项目展示与答辩：独立准备答辩材料并参加各级答辩。

承诺：本项目所有代码、模型、文档均为本人独立完成或
基于公开源码改进，无任何抄袭行为，无任何他人代笔情况。
```

## 常见问题

```
Q1: 我没有指导老师怎么办？
A: 找本院的任课老师/辅导员，说明这是 CRAIC 报名要求，
   挂名即可，不需要老师真的指导。

Q2: 学院不盖章怎么办？
A: 找院长助理 / 教学秘书 / 学工办老师，
   说明是 CRAIC 国家级竞赛要求，一般会配合。

Q3: 项目研究时间能不能往前填？
A: 严格不能早于本年度 7 月 1 日往前推 2 年。
   所以 2026 年比赛 → 不能早于 2024 年 7 月 1 日。

Q4: 单人队会不会扣分？
A: 不会。单人队 E 项（贡献度）反而是天然满分。
   只要把"项目分工"写详细。

Q5: 报名表能不能修改？
A: 提交前可改，提交后联系赛区老师。
   建议反复核对身份证号、邮编、专业全称。
```
