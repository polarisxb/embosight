# EmboSight 源码树清单

> 本目录是 CRAIC2026 代码提交用源码包。  
> 仅包含公开源码、配置、Prompt、测试和必要说明文件；不包含模型权重、API Key、日志、运行结果和演示视频。

## 目录总览

```text
EmboSight_source/
├── README.md                 # 项目说明、部署步骤、测试步骤、视频录制命令
├── LICENSE                   # MIT 开源许可证
├── requirements.txt          # Python 依赖列表；PyTorch CUDA wheel 按 README 单独安装
├── .env.example              # 环境变量模板，不包含真实 API Key
├── .gitignore                # 运行产物、模型权重、日志和敏感文件排除规则
├── configs/                  # 运行配置
├── eval/                     # 评估入口
├── prompts/                  # LLM/VLM Prompt 模板
├── scripts/                  # 部署、运行、验证、录制和实验脚本
├── src/                      # 核心源码
└── tests/                    # 单元测试和回归测试
```

## 核心源码树

```text
src/
├── __init__.py                       # 包入口和公开 API 导出
├── agent.py                          # EmboSightAgent 主循环，串联任务、感知、安全、抓取、执行

├── active_planner.py                 # 主动视角规划和离散视角库
├── perception.py                     # Query-aware grounding、缩放、视差、姿态感知流程
├── projection.py                     # 图像/深度到空间坐标的投影辅助
├── target_resolution.py              # 用户目标到仿真对象的解析
├── safety_gate.py                    # 高风险对象安全分类和门控
├── action_executor.py                # agent 动作执行封装
├── env_wrapper.py                    # RoboCasa / robosuite 环境封装
├── user_channel.py                   # CLI 和 fake user channel
├── episode_logger.py                 # episode 日志写入
├── memory_manager.py                 # 跨 episode 记忆管理
├── eval.py                           # 评估辅助入口
├── eval_oracle.py                    # episode 成败判定和 oracle 汇总
├── llm_backend.py                    # DeepSeek / OpenAI 兼容 LLM API 封装

├── vlm_cache.py                      # episode 内 VLM 缓存
├── clip_scorer.py                    # CLIP 语义评分辅助
├── grasp_profile.py                  # 抓取对象 profile 和策略参数
├── grasp_policy.py                   # 抓取候选策略选择
├── grasp_planner.py                  # 抓取候选生成和规划

├── grasp_execution.py                # 抓取执行过程
├── grasp_execution_recovery.py       # 抓取失败恢复逻辑
└── utils.py                          # 通用工具函数
```

## 推荐复现命令

轻量检查：

```bash
python -m pytest tests/test_public_api.py tests/test_run_agent_script.py tests/test_record_video_scripts.py -q
python -m ruff check src scripts eval tests
```

Linux/GPU 完整检查：

```bash
python scripts/verify_robocasa.py
python scripts/test_real_llm.py
python scripts/test_real_vlm.py
python eval/run_fixed.py --scenario fixed_lemon_001
python scripts/record_success_video.py --output results/videos/embosight_kitchen_success_lemon.mp4 --candidates fixed_lemon_001 --multi --fps 24 --frame-repeat 2 --min-frames 8
python scripts/record_success_video.py --output results/videos/embosight_kitchen_success_apple.mp4 --candidates fixed_apple_001 --hd --fps 24 --frame-repeat 2 --min-frames 8
```
