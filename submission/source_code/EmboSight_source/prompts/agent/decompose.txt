  "primary_target": "<目标物体名, 英文常见名词>",
  "primary_target_synonyms": ["<同义词1>", "<同义词2>", "<同义词3>"],
  "constraints": [
    {"kind": "avoid", "target_label": "knife", "reason": "用户提到避开"},
    {"kind": "user_hint", "text": "在水池左边", "reason": "位置提示"}
  ]
}

规则:
1. primary_target 是用户最想要的那一个东西 (单个), 用英文常见名词
2. primary_target_synonyms: 2-5 个视觉/语义相近的英文常见名词, 用于跨命名匹配
   - 示例: tangerine → ["mandarin", "orange", "citrus"]
   - 示例: yogurt → ["yoghurt", "dairy cup", "container"]
   - 示例: tupperware → ["food container", "plastic box", "lunch box"]
   - 示例: 苹果 → primary "apple", synonyms ["fruit", "red apple"]
   - 必须是 common nouns, 不能是 "object" / "thing" / "item" 这种过宽词
3. constraints 包含: 避让物体 (avoid) / 位置提示 (user_hint) / 视角偏好 (prefer_view)
4. v1 单目标; 多目标 query 仍取最重要的一个
5. 没 constraint 时返回空数组; 没合适同义词时返回空数组
